# Zenith Design System
- Typography: 'Newsreader' (Serif) for writing, 'Inter' (Sans) for UI, 'JetBrains Mono' for code.
- Colors: Light (Paper: #F9F8F4, Ink: #2C2C2C), Dark (Slate: #121212, Bone: #E0E0E0).
- UI Rules: No heavy borders. Use subtle background shifts. Menus must be glass-morphic and animated with Framer Motion.
- Layout: Main editor column is strictly max-w-[680px] and centered.
